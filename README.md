Este juego consiste en adivinar un número de tres cifras:

Se debe introducir un número de tres ciras y el programa devolverá cuantos números,comparando el introducido con el secreto, están en la posición correcta y cuantos están pero no en la posición correcta.

Si se acierta el número correcto, se pasará a una página de resultados donde te dice cual era el número y los intentos que has necesitado.

Si se hacen 10 intentos sin adivinar el número, el juego te avisa que se ha perdido la partida.
